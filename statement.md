# Project Statement

## Project Title

Student Records System

## Problem Statement

Managing student information manually can be difficult when there are many students, courses, and grades.

The Student Records System is designed to provide a simple way to store and manage student records using Python.

The system stores the student's name, registration number, enrolled courses, and grades.

It also allows users to check course enrollment and find students who are enrolled in a particular course.

## Scope of the Project

The project focuses on basic student record management.

The system can:

- Add new students
- Store registration numbers
- Store enrolled courses
- Add grades for courses
- Display student records
- Check course enrollment
- Find students enrolled in a particular course
- Add new courses to existing students

The current project is a basic Python application and stores data temporarily while the program is running.

## Target Users

The main target users are:

- Students learning Python programming
- Teachers for demonstrating basic programming concepts
- Small educational projects
- Beginners learning data management

## High-Level Features

### 1. Student Management

The system allows users to add new students along with their registration numbers and courses.

### 2. Grade Management

Users can add a grade for a particular course of a student.

### 3. Student Records

Users can view the complete information of all students.

### 4. Course Enrollment

The system can check whether a particular student is enrolled in a specific course.

### 5. Students by Course

The system can display all students who are enrolled in a particular course.

### 6. Add Course

Users can add a new course to an existing student's record.

### 7. Menu-Driven System

The program provides a simple menu so that users can select different operations.
