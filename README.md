# Student Records System

## Project Overview

The Student Records System is a simple Python-based project used to manage student information.

It allows the user to add students, store their registration numbers, add courses and grades, check course enrollment, and find students enrolled in a particular course.

The project uses Python dictionaries, lists, functions, loops, and conditional statements.

## Features

- Add a new student
- Store student registration number
- Add courses for a student
- Add grades for specific courses
- View all student records
- Check whether a student is enrolled in a course
- List students enrolled in a particular course
- Add a new course to an existing student
- Menu-driven program
