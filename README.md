# Student Records System

## Project Overview

The Student Records System is a simple Python-based project used to manage student information.

It allows the user to add students, store their registration numbers, add courses and grades, check course enrollment, and find students enrolled in a particular course.

The project uses Python dictionaries, lists, functions, loops, and conditional statements.

## Features

- Add a new student
- Store student registration number
- Add courses for a student
- Add grades for specific courses
- View all student records
- Check whether a student is enrolled in a course
- List students enrolled in a particular course
- Add a new course to an existing student
- Menu-driven program

## Technologies/Tools Used

- Python 3
- Python IDLE / VS Code
- Git
- GitHub

## Instructions for Testing

After running the program:

Select option 1 to add a student.
Enter the student's name.
Enter the registration number.
Enter the courses separated by commas.
Select option 2 to add a grade.
Enter the student name, course name, and grade.
Select option 3 to view all student records.
Select option 4 to check course enrollment.
Select option 5 to list students enrolled in a course.
Select option 6 to add another course.
Select option 7 to exit the program.
